# 🍪 Cookie Run Classic — คุกกี้รัน คลาสสิค

เกมวิ่งไม่รู้จบ (endless runner) สไตล์คุกกี้รันคลาสสิค สร้างด้วย HTML5 Canvas + JavaScript ล้วน ๆ
ไม่ต้องติดตั้งอะไรเลย — เปิด `index.html` ในเบราว์เซอร์แล้วเล่นได้ทันที ทั้งคอมและมือถือ

🎮 **เล่นออนไลน์:** https://candy-liart-five.vercel.app

## 🎮 วิธีเล่น

| ปุ่ม | การกระทำ |
|---|---|
| `SPACE` / `↑` / `W` | กระโดด (กดกลางอากาศ = ตีลังกา, นินจาโดดได้ 3 ชั้น) |
| `↓` / `S` (กดค้าง) | สไลด์ลอดสิ่งกีดขวาง / ดิ่งลงเร็วกลางอากาศ |
| `M` | เปิด/ปิดเสียง · `ESC` ออกจากหน้าย่อย |
| **มือถือ:** แตะครึ่งจอซ้าย | กระโดด |
| **มือถือ:** กดครึ่งจอขวาค้าง | สไลด์ |

## ✨ ระบบทั้งหมด (ครบแบบเกมจริง)

### การวิ่ง
- **แถบพลังคุกกี้** ลดตลอดเวลา หมดเมื่อไหร่จบเกม — ชน/ตกหลุมเสียพลังก้อนใหญ่
- **🚀 Rocket Start** พุ่งทะลุทุกอย่างตอนเริ่มเกม
- **⭐ BONUS TIME** เก็บดาวแล้วบินเก็บเยลลี่เต็มฟ้า อมตะ พลังไม่ลด
- **🏝️ ชั้นลอย** กระโดดขึ้นวิ่งชั้นบน เลือกเส้นทางบน/ล่าง
- เยลลี่แท่ง / เยลลี่ชมพู / เหรียญ / **หมีเยลลี่ +1000** พร้อมระบบ **คอมโบ**
- ไอเทม: ยาเพิ่มพลัง 🧪 · โหมดยักษ์ 🍭 · แม่เหล็ก 🧲
- **💖 ชุบชีวิต** ฟรีทุกรอบ · สิ่งกีดขวาง 4 แบบ + หลุมเหว
- **ด่านเร่งความเร็ว** พร้อมท้องฟ้าเปลี่ยนเวลา เช้า → กลางวัน → เย็น → คืนดาวเต็มฟ้า 🌙

### เมตาเกม (เหรียญสะสมถาวรในเครื่อง)
- **🍪 ตัวละคร 4 ตัว** ความสามารถต่างกัน: กล้าหาญ (สมดุล) · สตรอว์เบอร์รี (HP+25, กันตกหลุม) · นินจา (โดด 3 ชั้น, คอมโบนาน) · เทวดา (ชุบชีวิต 2, บูสต์นาน)
- **🐥 สัตว์เลี้ยง 3 ตัว**: มาการองน้อย (เก็บเยลลี่ให้) · ลูกเจี๊ยบทอฟฟี่ (เหรียญ x2) · ปุยเมฆน้ำตาล (ฟื้นพลัง)
- **🛍 ร้านค้าอัปเกรด 4 สาย** อย่างละ 5 เลเวล: เกราะน้ำตาล / จรวดคุกกี้ / พลังไอเทม / ดาวนำโชค
- **📜 ภารกิจ 10 ด่าน** ทำสำเร็จรับเหรียญโบนัส
- **🏆 ตารางอันดับ Top 10** ของเครื่อง พร้อมสถิติสูงสุด

ทั้งหมดบันทึกอัตโนมัติใน localStorage · เสียงเพลง chiptune จาก Web Audio API ไม่ใช้ไฟล์ภายนอก

## 🚀 รันเกม

```bash
python3 -m http.server 8000   # หรือเปิด index.html ตรง ๆ ได้เลย
```
