# 🍪 Cookie Run Classic — คุกกี้รัน คลาสสิค

เกมวิ่งไม่รู้จบ (endless runner) สไตล์คุกกี้รันคลาสสิค สร้างด้วย HTML5 Canvas + JavaScript ล้วน ๆ
ไม่ต้องติดตั้งอะไรเลย — เปิด `index.html` ในเบราว์เซอร์แล้วเล่นได้ทันที ทั้งคอมและมือถือ

## 🎮 วิธีเล่น

| ปุ่ม | การกระทำ |
|---|---|
| `SPACE` / `↑` / `W` | กระโดด (กด 2 ครั้ง = ตีลังกากลางอากาศ) |
| `↓` / `S` (กดค้าง) | สไลด์ลอดสิ่งกีดขวาง / ดิ่งลงเร็วกลางอากาศ |
| `M` | เปิด/ปิดเสียง |
| **มือถือ:** แตะครึ่งจอซ้าย | กระโดด |
| **มือถือ:** กดครึ่งจอขวาค้าง | สไลด์ |

## ✨ ระบบในเกม (แบบเกมจริง)

- **แถบพลังคุกกี้** ลดลงตลอดเวลา — หมดเมื่อไหร่จบเกม! ชนสิ่งกีดขวางหรือตกหลุมจะเสียพลังก้อนใหญ่
- **เยลลี่แท่งเหลือง / เยลลี่ชมพู / เหรียญ** วางเรียงตามเส้นทางกระโดด พร้อมระบบ **คอมโบ** ยิ่งเก็บต่อเนื่องยิ่งได้แต้มเยอะ
- **หมีเยลลี่** 🐻 ตัวโตแต้มหนัก +1000 พร้อมฟื้นพลัง
- **ยาเพิ่มพลัง** 🧪 ฟื้นแถบพลัง
- **โหมดยักษ์** 🍭 ตัวใหญ่ อมตะ พุ่งชนทำลายสิ่งกีดขวาง แต้มคูณสอง
- **แม่เหล็กเยลลี่** 🧲 ดูดเยลลี่รอบตัวอัตโนมัติ
- **สิ่งกีดขวาง**: เข็มลูกกวาด (กระโดดข้าม), หินช็อกโกแลต, คานแคนดี้เคน (ต้องสไลด์ลอด), หลุมเหว (กระโดดข้าม)
- **ด่านเร่งความเร็ว** — ทุก ๆ ระยะเกมจะเร็วขึ้นเรื่อย ๆ พร้อมป้าย SPEED UP!
- **สถิติสูงสุด** บันทึกอัตโนมัติในเครื่อง (localStorage)
- เพลงประกอบ + เอฟเฟกต์เสียง chiptune สร้างด้วย Web Audio API (ไม่ใช้ไฟล์เสียงภายนอก)

## 🚀 รันเกม

```bash
# เปิดไฟล์ตรง ๆ ได้เลย หรือรันเซิร์ฟเวอร์ง่าย ๆ:
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

สนุกกับการวิ่งนะ! 🏃💨
